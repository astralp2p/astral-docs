# ether

The `ether` protocol carries public, connectionless messages across a broadcast network such as a local area network. It is used for node presence and discovery: a node pushes a small typed object to every peer reachable on the same broadcast segment, and listening nodes learn who is nearby.

Messages travel over UDP. The node binds a single UDP socket on the ether port (8822 by default) and sends each message as one datagram to the IPv4 broadcast address of every eligible, non-loopback, non-link-local interface, deduplicating addresses shared across interfaces. A message may also be unicast to a single IP. Every datagram carries one `mod.ether.signed_broadcast`: a `mod.ether.broadcast` payload — timestamp, source identity, and the object being announced — together with a signature. The source of a broadcast is always the sending node: the node puts its own identity in `Source` and signs with its own node key; a node never sends a broadcast under another source. The signed input is the 32-byte [`Object Hash`](../../core-definitions/object-id.md) of the broadcast payload, the SHA256 hash of its canonical form without the `Object Size`, so the signature covers the payload but not the signature field itself.

On receipt a node drops its own broadcasts, drops any datagram without a signature, and verifies the signature against the `Source` identity's key. It then delivers the announced object to its object receivers with `Source` as the sender, and surfaces the broadcast locally as a `mod.ether.events.broadcast_received` event.
