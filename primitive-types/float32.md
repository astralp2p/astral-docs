# float32

Basic single-precision floating-point type.

## Binary Encoding

An IEEE 754 single-precision floating-point value (4 bytes).

## JSON Encoding

A JSON number.

## Text Encoding

The decimal string representation of the value.

## Example

`1.5`, in each encoding:

```
binary   3f c0 00 00
json     1.5
text     1.5
```
